## Usage rules

- Use only approved, original SVG files from the brand system. Do not redraw, approximate, distort
  or scale non-uniformly, and never clip them.
- Elements marked *proposed / study* in the brandbook are not final production assets.
- Light mode: `#FFFFFF` canvas, `#111111` artwork. Dark mode: `#111111` canvas; CHAIN artwork
  `#161616`; a logo, once added, is reversed to `#FFFFFF`.
- Keep a clear space of at least 3U around the logo (the mark is 57U x 30U).

## Files

The stylesheet `docs/theme/robonomics.css` references these files. Without them the site falls back
to plain text and stays readable.

```text
assets/brand/
  chain/chain-horizontal-light.svg         CHAIN horizontal chain tile, #111111 artwork
  chain/chain-horizontal-inverse.svg       same tile, #161616 artwork for the dark canvas
  BRAND-NOTICE.md                          this file
```

Both chain files are the approved `RB-PAT-robonomics-HOR-12` pattern from the Robonomics asset
library. Only the colour was changed; the geometry is untouched.
